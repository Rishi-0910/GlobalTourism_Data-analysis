# 📊 Data Analysis & Visualization Project

## 📌 Overview

This repository contains a collection of Jupyter Notebook (`.ipynb`) files focused on **Exploratory Data Analysis (EDA)** and **Data Visualization**.
The project aims to analyze datasets and extract meaningful insights using Python libraries like **Pandas, NumPy, Matplotlib, and Seaborn**.

## 🚀 How to Run

1. Clone the repository
2. Install required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```
3. Open notebooks using:

   ```bash
   jupyter notebook
   ```
